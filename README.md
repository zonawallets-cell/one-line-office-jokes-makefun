One-line office joke: a squeaky chair turns every stand-up into an unscheduled speech.

The entry:

> `My chair squeaks, so every time I stand up the whole office thinks I'm giving a speech.`

87 characters, one line, valid UTF-8 — inside the 199-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–199 characters, single line, non-whitespace, valid UTF-8) before and after writing.
